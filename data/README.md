# Data Directory

Contains healthcare claims datasets used for model training, feature extraction, and testing:
- **Inpatient Data**: Hospitalization admission/discharge dates, procedure codes, and reimbursements.
- **Outpatient Data**: Routine clinic visits and day-care consultations.
- **Beneficiary Data**: Patient demographic profiles tracking 11 chronic illnesses.
- **Provider Ground Truth**: Historical audit labels used for supervised classification.
