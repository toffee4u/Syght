# Frontend Web Dashboard
<!-- Student Academic Project: React Web Application (Vite + Tailwind CSS) -->

Modern, responsive web dashboard built with React 19, Vite, and Tailwind CSS:
- **Command Center**: Real-time fraud metrics, volume gauges, and risk distributions.
- **Pre-Auth Gateway**: Instant simulation of incoming claims evaluated with sub-5ms latency.
- **Review Queue**: Interactive SHAP feature importance visualizer for investigators.
- **Collusion Network**: Force-directed network diagram exposing doctor-sharing rings.
- **Dataset Studio**: Interactive scanner supporting multi-table, single-claim, and custom CSV formats with AI sample prompt generation.
