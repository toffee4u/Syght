# Syght Benchmark Reports Directory

This directory stores reproducible evaluation summaries, performance tables, operational queue benchmarks, and visualization assets generated by the Syght ML pipeline.

---

## 1. Directory Contents

When benchmark runs are executed (locally or in Google Colab), the following files are produced:

- **`benchmark_report.md`**: Human-readable Markdown summary including:
  - Ingestion and pre-flight audit results
  - Cross-validation candidate scores (PR-AUC, ROC-AUC, Brier score)
  - Baseline justification verification (ML vs. simple billing volume rules)
  - Held-out test metrics with 95% bootstrap confidence intervals
  - Cost-aware threshold analysis & sensitivity tables
  - Top-K investigation queue performance (1%, 5%, 10%, 20% capacity)
  - Global risk factors with plain-language translations
- **`benchmark_report.json`**: Machine-readable JSON output for automated ingestion, dashboard reporting, or CI regression testing.
- **`figures/`**: High-resolution evaluation plots:
  - `pr_curve.png`: Precision-Recall curve comparing the model against the no-skill baseline.
  - `roc_curve.png`: Receiver Operating Characteristic curve.
  - `confusion_matrix.png`: Annotated classification heatmap at the chosen decision threshold.
  - `cost_curve.png`: Expected insurer operational cost vs. decision threshold.
  - `shap_summary.png`: SHAP feature importance and directionality plot.

---

## 2. Operational Notice for Review Teams

Reports generated by Syght provide **decision support to prioritize audit workloads**.
- Metrics must always be interpreted in the context of the **~9.4% fraud base rate**; accuracy alone is never used to judge model efficacy.
- Feature attributions reflect correlation with historical audit outcomes, not causal or legal proof of fraud.
