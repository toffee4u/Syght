# Machine Learning Pipeline
<!-- Student Academic Project: Healthcare Insurance Fraud Detection ML Engine -->

Core Python pipeline modules for feature engineering, model training, and Azure AI tools:
- **Feature Engineering**: Calculates 61 provider-level forensic behavioral features from multi-table claims data.
- **Model Training & Evaluation**: Stratified cross-validation benchmark across tree ensembles and linear baselines.
- **`azure_ml_integration.py`**: Azure ML SDK v2 pipeline specifications and managed online endpoint config (Unit-2 Exp 2).
- **`genai_agent_system.py`**: Autonomous 4-agent collaborative fraud investigation system (Unit-2 Exp 2).
- **`nlp_clinical_analyzer.py`**: Clinical NLP for doctor notes and Azure AI Document Intelligence connectors (Unit-2 Exp 3).
